# Einheit 1 – Verständnisfragen

## 1. Was ist der Unterschied zwischen Capacitor und Cordova?

Beides sind Tools, um Web-Applikationen, die mit HMTL, CSS und JavaScript gemacht wurden als Apps für Smartphones nutzbar zu machen. Cordova ist die ältere Version, die viel mit Plugins arbeitet, um auf Funktionen wie die Kamera zuzugreifen. Capacitor ist die modernere Lösung von Ionic und funktioniert ähnlich, ist aber besser für modernere Projekte geeignet. 

## 2. Was macht ein ORM wie Sequelize, und wofür braucht man zusätzlich die sequelize-cli?

Sequelize ist dafür da, die Verbindung zwischen Anwendung und einer Datenbank herzustellen. Die sequelize-cli wird verwendet, um Sequelize über die Commandline zu bedienen.

## 3. Was unterscheidet npm install von npx beim Ausführen eines Pakets?

Mit npm install werden Packages installiert. Mit npx können Packages bzw. deren Befehle ausgeführt werden. npm steht für Node Package Manager und npx für Node Package Execute.

## 4. Was ist REST, und warum passt das Konzept zu einer Client-Server-Architektur wie Ionic-App und Node-Backend?

REST ist eine Art, wie Client und Server miteinander kommunizieren, in diesem Fall über HTTP. Die Ionic-App ist hier der Client, der einen Request für Daten schickt. Das Node-Backend ist bei uns der Server, der die Response mit den Daten schickt.
